# Space Tiger Client Package Scopes

Internal reference only — never quote prices or package names to the client in the
Hypothesis Doc. Use this to decide which tier a hypothesis belongs to (Enablement /
Automation / Custom) and to sanity-check that the hypothesis is actually scoped the
way Space Tiger sells it.

## Tier 1 — AI Enablement
**From $3,500 · 6 weeks**

For a client whose team isn't using AI tools (ChatGPT, Claude, Copilot, etc.)
consistently or at all. Space Tiger picks the right tools, sets them up, and coaches
adoption so it sticks. No engineers — strategy team delivers education/enablement.

- Evaluate and recommend 3 tools for the team
- Account setup, connect to existing systems (Google or M365)
- Weekly 60-min implementation call (6 weeks); week 6 = before/after + propose next build
- Simple day-to-day usage guide
- 30-day written check-in

**Signal for this tier:** a capable person doing a task often, following a predictable
pattern each time — but no tool is in place, or it's used inconsistently. The human
keeps doing the work; AI makes them faster.

## Tier 2a — Single Workflow (Automation)
**Starting at $2,500 · 2 weeks**

One manual process someone does the same way every time. Space Tiger documents it
exactly, automates it, hands it off to run on its own.

- Written spec approved before build
- One deployed automation connecting existing tools
- Basic error alerts (email)
- Recorded walkthrough
- 30 days of tuning + follow-up call

**Signal for this tier:** repetitive, predictable, triggered by a consistent event, no
judgment required to complete — and it's a single process, not several linked ones.

## Tier 2b — Workflow System (Automation)
**From $3,000–$8,000 · 4–6 weeks**

Multiple connected manual processes — one feeds into another, or several teams touch
the same information differently. Space Tiger maps the whole system, automates each
piece, makes them work together.

- Full workflow map approved before build
- 3–4 deployed automations working as a system
- Live monitoring dashboard
- Runbook + recorded walkthrough per automation
- 30 days of tuning + follow-up call

**Signal for this tier:** same as 2a, but the client described more than one linked
process, or a handoff between systems/teams — not just one isolated task.

## Tier 3 — Custom AI Systems
**From $3,500–$20,000+ · 8–16 weeks**

A process that requires real judgment (reviewing contracts, answering complex
customer questions, analyzing data across the business). Space Tiger builds a custom
AI system that replicates that expertise.

- Full design doc approved before any build
- One AI agent or knowledge system, deployed
- Two live delivery checkpoints
- Admin training session, full documentation
- 30-day warranty

**Signal for this tier:** the need is unique to this client — requires custom logic,
proprietary data, or judgment that no off-the-shelf tool or simple automation covers.
