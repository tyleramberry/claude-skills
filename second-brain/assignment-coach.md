# Skill: Assignment Coach

## Trigger
"Help with this assignment", paste prompt, "draft outline for CASE-2", "check my paper against the rubric".

## Procedure
1. Load course page + extracted syllabus (rubric, AI policy, late policy)
2. Create/update `projects/byu-strategy/assignments/COURSE-short-name.md`:
   - Prompt summary
   - Due date / status
   - Rubric checklist
   - Outline / draft sections
   - Sources from *his* notes/readings (search `notes/`, `readings/`)
3. Draft only what he asks (outline vs full draft vs edit)
4. Flag honor-code / AI-policy constraints from syllabus explicitly
5. Update DEADLINES status when submitted
6. log.md

## Done when
Assignment file updated; next actions clear. Do not submit anything for him.
