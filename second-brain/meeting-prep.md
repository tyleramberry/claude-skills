# Skill: Meeting Prep

## Trigger
User: "prep me for meeting with X" / before calendar event once wired.

## Procedure
1. Identify person(s) — open or create `people/<slug>.md`
2. Search library for prior notes, decisions, open loops (`search_files`)
3. Pull project pages related to the meeting
4. Draft prep dock:

```
# Meeting prep — <who> — YYYY-MM-DD
## Who
## Last touchpoints
## What changed since
## Their likely ask
## Your goals
## Questions to ask
## Watch-outs
## Links
```

5. Save `logs/meeting-preps/YYYY-MM-DD-<slug>.md`
6. Update person page `updated` + last-meeting note
7. log.md entry

## Done when
Prep file saved and summary delivered.
