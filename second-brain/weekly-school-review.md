# Skill: Weekly School Review

## Trigger
Sunday evening / "school week ahead" / optional cron.

## Procedure
1. Read `projects/byu-strategy/DEADLINES.md` + each `courses/*.md`
2. Build:
   - Due in next 7 days (priority)
   - Due in 8–21 days (start early?)
   - Missing notes for classes that met (if detectable)
   - Group project open loops
3. Suggest a simple time block plan (school vs UVY vs venture) — latent judgment, light touch
4. Write `projects/byu-strategy/admin/week-YYYY-MM-DD.md`
5. Surface top items into chat; optionally feed morning brief

## Done when
Week file written; Tyler sees ranked deadlines.
