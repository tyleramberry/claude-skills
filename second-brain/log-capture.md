# Skill: Log Capture

## Trigger
In any conversation, Tyler mentions: business idea, AI development, workout/sleep/habit, finance update, UVY job/revenue/task, decision worth remembering.

## Procedure
1. Classify → correct wiki log or page
2. Append dated entry (most recent first where logs use that convention)
3. If person/project newly important, create page per SCHEMA thresholds
4. Touch index if new page
5. Confirm to Tyler in one line what was logged where

## Never
Invent numbers. If incomplete, log qualitative note and mark open question.

## Done when
Durable fact is on disk, not only in chat.
