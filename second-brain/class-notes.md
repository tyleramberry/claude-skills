# Skill: Class Notes

## Trigger
"Notes for COURSE", "file these lecture notes", post-class dump, photo/OCR of whiteboard.

## Procedure
1. Identify course code (ask once only if impossible to infer)
2. Write `projects/byu-strategy/notes/COURSE_CODE/YYYY-MM-DD-slug.md` with frontmatter
3. Structure:
   - Takeaways (3–7 bullets)
   - Detailed notes
   - Questions / confusions
   - Action items (readings, homework)
   - Links to related assignments or prior notes
4. If action items have dates → add/update `DEADLINES.md`
5. Optionally link a concept worth keeping long-term into `wiki/concepts/` (only if reusable beyond the class)
6. log.md entry

## Done when
Note file saved; Tyler gets path + 3 takeaways back.
